# AutoTS releases

Installers for **AutoTS**, a personal time-tracking desktop app for Windows and macOS.

This repository holds nothing but release downloads — no source. It is public so that
the app's updater can read its release feed without shipping a credential inside the
binary.

Grab the latest installer from [Releases](../../releases). Installed copies check here
on their own and offer an update; downloading and installing are always a button, never
automatic.

The builds are unsigned, so Windows SmartScreen warns on first run — *More info → Run
anyway*.
